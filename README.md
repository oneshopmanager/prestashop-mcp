# One Shop Manager — MCP server for PrestaShop 1.6 to 9

One Shop Manager lets Claude, or any other MCP client, read a PrestaShop store and prepare changes that the merchant reviews and approves before anything is sent to the store.

[Français](README.fr.md) · [Website](https://oneshopmanager.com/en/) · [Claude + PrestaShop](https://oneshopmanager.com/claude-prestashop)

## What it is

One Shop Manager is a desktop application for macOS 11+ and Windows 10+. It copies the store to the computer and exposes it to MCP clients through a **local MCP server**. A small PrestaShop module connects the application to the store webservice.

- Server name: `one-shop-manager`
- Transport: Streamable HTTP on `http://127.0.0.1:47715/mcp` (port can be changed), or stdio through the application executable (`--mcp <ACCESS_KEY>`)
- Authentication: a bearer access key generated by the application
- Scope: the store currently open in the application

This repository contains documentation only. The One Shop Manager software is commercial and is not open source.

## What the AI can read

Answers come from the local copy of the store, without querying the live site for every question.

- **Catalog**: products, texts in every language, categories, attributes and combinations
- **Customers and orders**: customer search and details, order list and details with gross margin
- **Analysis**: sales report, product sales and unsold products, stock valuation, restock, SEO audit, saved tables
- **Accounting**: period summary with VAT by country and rate, invoices and credit slips to check, entries for one order
- **Journal**: past operations and the status of AI proposals

## What the AI can propose

- Prices, field values and cell edits, texts and SEO fields, categories and category texts
- Product creation and duplication (created disabled)
- Attributes, attribute values and combinations, combination stock
- Order status, tracking numbers, new orders for an existing customer
- Undoing a past operation

The full list, with every tool and its type, is in [docs/tools.md](docs/tools.md).

## The approval rule

Nothing is written to the store until the user opens the before/after preview and clicks Apply. Every `propose_*` tool computes the change and files it as a proposal in **AI assistant › AI log** inside the application; the AI has no tool that writes to the store. Applied changes can be undone from the journal (except created orders).

A **read-only** mode hides all proposal tools from the AI.

## Quick start

1. Download the 14-day free trial from [oneshopmanager.com](https://oneshopmanager.com/en/) and connect your store.
2. In the application: **Settings › AI settings**, card **AI access (MCP)**: check **Enable AI access**, then click **Test access**.
3. Connect your client:
   - [Claude Desktop](docs/clients/claude-desktop.md): one button, **Connect Claude Desktop**, or the extension `prestashop-mcp.mcpb` from the [Releases](https://github.com/oneshopmanager/prestashop-mcp/releases)
   - [Claude Code](docs/clients/claude-code.md): one command to paste
   - [Cursor](docs/clients/cursor.md)
   - [Other MCP clients](docs/clients/other-clients.md), including Codex
4. Ask: "How many active products does my store have?" The application must stay open on that store.

## Security

- AI access is disabled by default.
- The MCP connection is local to the computer and protected by an access key.
- Store credentials stay in the system keychain, out of the AI's reach.
- Only the data needed for a question is sent to the AI provider; with your own Claude, it goes directly to Anthropic.
- Nothing is written without approval, and everything can be undone.

Details in [docs/security.md](docs/security.md).
